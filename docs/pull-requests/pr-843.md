# [PR 843](https://github.com/vig-os/tessera/pull/843) docs(adr): accept ADR-0065, the C ABI bridge for C++ producers

The owner accepted ADR-0065 (the C ABI bridge for C++ producers) as written on 2026-11-13, with rulings on its two
owner decision points:

1. **H4 (NaN payloads): canonicalised at the bridge.** The bridge calls `tessera-ingest`'s `canonicalise_floats`
   and records the `IngestTransform` in the seal, exactly as ingest does. The ADR's recommendation becomes the
   decision.
2. **Stall deadline: mandatory.** There is no "no stall deadline" opt-in. The finite deadline applies to every
   session: default 10 min, cap 24 h, `0` = the default, expiry `TSRA_E_STALL`.

What changes:

- ADR-0065: the status line reads "Accepted (2026-11-13)" and names both rulings. Decision items 2 and 3, §1 (the H4
  option list, now "decided"/"rejected"), §7.2 (the former owner decision point), §9 (the transform), §15 (the plan
  no longer waits for acceptance) and §16 now state these as decided, with the date.
- `docs/adr/README.md`: the row's status is **Accepted** (2026-11-13), and it records the two rulings.
- `tessera/docs/FEATURE-MATRIX.md`: the C ABI row cites ADR-0065 as Accepted, and the NaN gate states the decision.

Docs only. Implementation follows ADR-0065 §15. #800 stays open and closes with the bridge.
