# [PR 1042](https://github.com/vig-os/tessera/pull/1042) fix(ingest): avoid inheriting HDF5 writer handles in tests

The skip-message test added in #1031 spawned child test processes while parallel libtest workers could hold HDF5 fixture writers open. The sec2 driver opens descriptors without close-on-exec, so a child retained an exclusive writer lock after the parent closed every HDF5 object. The next read then failed with errno 11.

Test the opt-in decision and exact skip message directly in process. Add repeated write/read/stream/rewrite cycles for all three fixture writers while exercising the opt-in check concurrently, plus concurrent readers followed by rewriting the same file. The retained regression fails when the old subprocess implementation is restored.

The production streaming producer owns its HDF5 reads; encoder workers receive decoded slabs. Concurrent read-only opens are covered by the shared-file regression.
