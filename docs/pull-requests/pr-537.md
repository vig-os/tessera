# [PR 537](https://github.com/vig-os/tessera/pull/537) ci: run the bench method tests, and fail when any test file is visible to no check

**Stacked on #521** (it adds `test_common.py`); review that first. Retarget to `dev` once #521 merges.

The ecosystem bench's tests gated nothing: `tessera/bench/ecosystems` is referenced by no check, workflow, hook or recipe, and `/bench/` is not in the crane `src` filter. This is the **second occurrence** of the class — `ef240cb` fixed trycmd running zero cases in CI for the same reason — so this adds a structural guard, not just a path.

## `bench-ecosystems` (new check)

Runs `test_common.py`: median+spread, **measured** cold-cache eviction, both table and both volume fixtures. Pure Python + numpy — no ecosystem libraries, no `tessera-py` — so it is cheap. Source is **only** `common.py` + `test_common.py` (`builtins.path` with a filter), so editing an adapter or the driver neither rebuilds it nor moves the crane `src` hash.

17 passed in the sandbox, on `ext2/ext3` — a real page cache, so the eviction tests are genuinely testing eviction. (On tmpfs `DONTNEED` is a no-op; the check prints the filesystem type so a failure there is diagnosable.)

## `test-coverage` (new check)

Every test-like tracked file — under `tests/`, `test_*.py`, `*_test.py`, `*.trycmd` — must be:

1. admitted by `srcFilter` (the crane checks see it), **or**
2. listed in `testsRunOutsideCraneSrc` with the check that runs it, **or**
3. declared in `testsDeferredFromCi` **with a reason**.

Listed entries that no longer exist fail too, so the lists can't rot into false reassurance. Exact **files**, not directories: a new script dropped beside `smoke.py` but never wired in is exactly the failure this catches.

It's a named check rather than an eval-time `throw`, so it shows in the summary and doesn't collide with #536's wrapper around the checks attrset.

**Today's inventory:** 81 test-like files, 8 outside the filter — 6 already run by path (`tessera-py-import`, `ingest-producer-equality`, `wasm-bindgen-smoke`), `test_common.py` now run by `bench-ecosystems`, and `test_adapters.py` **deferred with its reason**: it needs h5py, zarr, pyarrow, nibabel, pydicom, uproot *and* a built `tessera-py` — a heavy new derivation, waiting on the CI memory work (#495).

## Verified in both directions

| case | result |
|---|---|
| current tree | passes, and prints the one declared deferral |
| `test_common.py` unlisted | **fails:** `ORPHAN /bench/ecosystems/test_common.py: not admitted by srcFilter and run by no check` |
| a nonexistent file listed | **fails:** `STALE /bench/ecosystems/test_gone.py: listed in flake.nix but no such file` |

## No rebuild cost

The crane filter became a named `srcFilter` so the guard asks the *same* predicate the build uses rather than a copy. `workspace-test`'s derivation path is **byte-identical** before and after this change, so the `src` hash didn't move and no Rust derivation rebuilds.

Closes #520
