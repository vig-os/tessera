# [PR 451](https://github.com/vig-os/tessera/pull/451) fix(ci): accept the repo's documented branch types in the devkit branch-name gate

Closes #450

The devkit scaffold's branch-name gate (#442) fell back to the devkit default type list because `DEVKIT_BRANCH_TYPES` was empty in `.vig-os`. That list rejects `fix/`, `feat/`, `ci/`, `perf/`, `chore/` … branches, which the local pre-commit branch-name hook and `docs/COMMIT_MESSAGE_STANDARD.md` allow. Branches passed on commit and failed after push (#447, and the in-flight CI-hygiene work).

This sets `DEVKIT_BRANCH_TYPES` to the exact type set of the pre-commit hook (plus `release`), so both gates enforce one convention. The values match the resolver's `^[a-z][a-z0-9]*$` entry validator.
