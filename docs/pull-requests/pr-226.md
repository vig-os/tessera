# [PR 226](https://github.com/vig-os/tessera/pull/226) chore(deps): patch Python bench lockfile — clears 38/40 Dependabot alerts

## What

Patches the Python **bench/dev** lockfile (`uv.lock`) to upstream-fixed versions, closing **38 of 40** open Dependabot alerts (including the lone **critical**).

## Why it's low-risk

All 40 alerts are **pip** (`uv.lock`) — the dev/bench tooling. The **shipped Rust crates have zero alerts**. The bulk is the Jupyter notebook stack pulled in by the root `fd5` scaffold's `dev` extra (`jupyter`/`ipykernel`) — installed by CI's `uv sync --all-extras` but never exercised by `uv run pytest`.

No `pyproject.toml` change — this is a pure lockfile bump via `uv lock --upgrade-package`, so dependency *constraints* are untouched.

## Upgrades

| package | before → after | clears |
|---|---|---|
| jupyter-server | 2.17.0 → 2.20.0 | **critical** + highs |
| jupyterlab | 4.5.5 → 4.6.1 | high |
| notebook | 7.5.4 → 7.6.0 | high |
| tornado | 6.5.4 → 6.5.7 | highs |
| pillow | 12.1.1 → 12.2.0 | high |
| urllib3 | 2.6.3 → 2.7.0 | high |
| mistune | 3.2.0 → 3.3.2 | high |
| requests | 2.32.5 → 2.34.2 | medium |
| idna | 3.11 → 3.18 | medium |
| nbconvert | 7.17.0 → 7.17.1 | medium |
| pygments | 2.19.2 → 2.20.0 | low |
| bleach | 6.3.0 → 6.4.0 | medium/low |
| pytest | 9.0.2 → 9.1.1 | medium |

The **2 residual mediums** (transitive `bleach` + `mistune`) have **no upstream fix yet** — already at latest.

## Verification

- `uv lock --check` — clean
- `uv sync --frozen --all-extras` — resolves (the exact CI command)
- `uv run pytest` — green (2 passed) under pytest 9.1.1

`uv.lock` is not a Nix build input, so the Rust `nix flake check` gate is unaffected.
