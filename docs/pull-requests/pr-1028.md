# [PR 1028](https://github.com/vig-os/tessera/pull/1028) feat(io): commit_collection, log and history (ADR-0067 step 5)

Closes #1000
Refs: #947

Adds atomic collection commits under the repository writer fence: caller-tip CAS, fixed lineage kind and identity,
exact supersedes pins, recursive member closure, and products/payloads/sub-collections supplied in the same call.
Validation finishes before storage; blocks, products and nested collections become durable before publishing the ref.
Collection commits append the existing oldest-first log cache.

Adds sealed ancestry records from any product or collection version, in depth-first preorder with supersedes before
forked_from and shared ancestors returned once. Missing or unreadable predecessors return HistoryAborted with bounded
edge provenance. ADR-0067 records the 2026-11-27 contract clarification; ADR-0036, the book and unreleased changelogs
explain the public API and failure modes.
