# [PR 820](https://github.com/vig-os/tessera/pull/820) docs(spikes): gap analysis of the C++ consumers against tessera's format and writer

## What

A docs-only spike: `docs/spikes/801-consumer-gap-analysis.md`, plus draft product schemas in `docs/spikes/801-consumer-schemas/`. It covers what the #799 C++ consumers (gPET-sim/g4h5, gPET-sim2listmode, geddf-analysis, gPET-readout, gPET-pipeline) write and read today, and what tessera's format and writer must offer them. No product code changes.

- **§2 Inventory.** For each consumer: columns, dtypes, sentinels, volumes, how many producer threads write and in what order. Each fact cites a file and line at a pinned commit, and inferred facts are marked.
- **§3 Gap table.** 37 rows, each marked needed / exists / partial against tessera at `6a30780` with file:line, plus the issue it belongs to.
- **§4 Ordering (#802).**
  - From the Geant4 task run manager sources, event *i* gets seed pair *i*. So each event's content is fixed whatever the thread count; only the interleaving changes.
  - The key is `event_id` within one run and `(run_id, event_id)` across batches, because the on-disk id is `uint32` + offset. `(thread, sequence)` is rejected.
  - The section ends with the writer requirements this implies, as input to #802's design.
- **§5 Draft schemas (#801).** Each consumer product gets two files:
  - a `ProductSchema` exactly as serde writes it;
  - a proposed per-role `Column` contract with `sequence_key`, `keys` and `references`.

  `generate.py` is the source of the JSON. `check.py` checks the drafts against the Rust serde shapes; it is a Python mirror of those types, not a Rust round-trip.
- **§6 Reader ports (#803).** Call sites, the tessera replacement, and S/M/L effort per repo.
- **§7** lists questions for the owner's surveys, which supersede this note.

New gaps filed: #804 (Python nullable read defect), #805 (C ABI read side), #806 (streamed table without an up-front row count), #807 (Python row-range reads).

## Checks

- `prek run --files <changed>`: all hooks pass.
- `check.py` exits 0 on the drafts and 1 on a mutated copy (a bad dtype and an undeclared key column).
- `generate.py` regenerates byte-identical JSON.
- A fresh-context review checked about 45 citations, all of which hold. It approved with nits, and all of them are applied.
