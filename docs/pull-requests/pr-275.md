# [PR 275](https://github.com/vig-os/tessera/pull/275) fix(export): PHI-safe + valid JSON-LD FAIR records — opaque source URNs, not raw paths (#267)

The #1 usability-review finding (4/5 reviewers): `export` baked absolute host paths + patient name/MRN into the record AND emitted invalid JSON-LD (256KB comma-joined `@id`). Now each provenance edge → an opaque `urn:tessera:source:<merkle-hash>` (File/Dataset entity in `@graph` with the merkle sha256); `isBasedOn`/`relatedIdentifier` reference it. Proven: PHI-leak regression test + live `export ct-lung.tsra` leaks neither CHERICO nor paths. Display-only (no seal change). Export half of #267; provenance-as-list data-model half remains. Gate green.
