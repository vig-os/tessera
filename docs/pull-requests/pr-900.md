# [PR 900](https://github.com/vig-os/tessera/pull/900) docs(spike): seal-encoding bake-off A vs A′ vs B and ADR-0066 (accepted: A′)

**Decided: A′ (owner, 2026-11-18).** ADR-0066 is now **Accepted**. Its implementation plan has four ordered items, each with scope, acceptance criteria and dependencies, for filing as sub-issues of #897:
1. #895
2. writers emit JCS
3. the stored-bytes API in core
4. the format cutover, which resolves the reader split of #901

The ADR index marks ADR-0066 Accepted and notes on the rows of ADR-0020, 0022, 0037, 0054 and 0060 that ADR-0066 amends them. The amendments themselves land with the implementation.

This PR is the evidence for the decision in #897, plus ADR-0066. It changes no product code, SPEC, corpus or golden.

- Spike: `docs/spikes/897-seal-encoding.md` (verdict table first)
- ADR: `docs/adr/0066-seal-encoding.md` (+ index row)
- Prototypes and raw results: `docs/spikes/897-seal-encoding/`. `run.sh` regenerates every `results/*` file byte-for-byte (verified twice).

## Options
- **A**: alpha.6 as PR #894 ships it (JCS, re-serialise and hash), plus #895.
- **A′**: `manifest.json` stored as exactly its JCS bytes. The seal is `blake3` of the stored bytes, held in a `manifest.seal` member. Readers refuse non-canonical bytes and keep I-JSON.
- **B**: deterministic CBOR (RFC 8949 §4.2.1) with dCBOR-style numeric reduction. B0 (without reduction) is kept as a contrast.

## Headline numbers (13 tracked `.tsra`)

|---|---|---|---|
| Respellings that keep the seal and verify (59) | **59/59** | 0/59 | 0/33 verify (33 refused); 26 have no form |

| Legibility (fresh agent, no docs) | n/a | 5/5, `jq` | 5/5, needs `cbor2` |
| New deps | none | none | CBOR codec + own strict decoder ×3 |

**Recommendation (accepted): A′ with #895.** A′ and B are equally sound on the attack replay. The choice is native 64-bit integers (B) against keeping every seal and signature, no new dependency, stock writers, and `jq` legibility (A′). For readers, A′ requires both the canonical check (S7) and I-JSON (S5b). Migration: refuse the alpha layout and convert it with a seal-preserving `tessera migrate`.

## Proof
- `cargo test --release` (spike crate): 4/4 pass. These cover the profile codec at the 64-bit edges, preferred floats incl. f16 subnormals, numeric reduction, and every refused form.
- `./run.sh`: exit 0. Python (`jcs` 0.2.1, `cbor2` 6.3.0) and node (`canonicalize` 5.1.0, `cbor-x` 1.6.9) run on the same bytes. Float formatting agrees on 200,000/200,000 doubles in Rust, Python and JS.
- Two fresh-context review rounds. Round 1 blocked on three points, all fixed: the reader-side I-JSON claim, numbers not backed by a result file, and B judged without numeric reduction. Round 2 approved with nits, which are applied.

## Gate configuration (two lines)
- `.pre-commit-config.yaml`: `no-debug-leftovers` now also excludes this spike's Python and JS reader probes. Their printed report is their output, the same rationale as the existing bench/corpus `run.py` exclusion.
- `_typos.toml`: COSE (RFC 9052) is allowlisted.

Not done, by scope: no issues filed (the cost section lists ordered sub-issues per option), and nothing touches PR #894's branch.
