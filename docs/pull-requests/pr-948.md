# [PR 948](https://github.com/vig-os/tessera/pull/948) chore: keep Python bytecode out of worktrees

Closes #880

Running the reference reader outside nix left an untracked `__pycache__/`, dirtying every worktree. Two fixes:

- `__pycache__/` and `*.py[cod]` added to `.gitignore` and `.gitignore.project` (the durable source devkit regenerates the root file from). `git ls-files -ci --exclude-standard` is empty after the change.
- The reader and its two generators (`run.py`, `make_seal_cases.py`, `make_refusal_fixtures.py`) are documented with `python -B` (README and generator docstrings). These are the only in-repo non-nix call sites: no justfile, Makefile, CONTRIBUTING or book command invokes them; the flake runs them inside the sandbox and is untouched.

Proof, scratch git repos of `origin/dev` (before) and this branch (after), `uv run --no-project`, no .venv:

| | run | `git status --porcelain` |
|---|---|---|
| before | `python run.py`, rc=0 | `?? tessera/corpus/reference_reader/__pycache__/` |
| after | `python -B run.py`, rc=0 | empty, and no `__pycache__` written |

`git check-ignore -v` results relied on:

```text
.gitignore:57:__pycache__/	tessera/corpus/reference_reader/__pycache__/reader.cpython-312.pyc
.gitignore:58:*.py[cod]	a/b.pyc
.gitignore:58:*.py[cod]	a/b.pyo
.gitignore:58:*.py[cod]	a/b.pyd
```

`git check-ignore -v tessera/corpus/reference_reader/run.py` matches nothing (rc=1): sources stay tracked.
