# [PR 750](https://github.com/vig-os/tessera/pull/750) feat(io)!: deprecate table_job_streaming, refusing tables above BLOCK_ROWS

Closes #713

Part 3 of 3 of ADR-0064 PR E. It deprecates `table_job_streaming` and withdraws its alpha.4 "any size" contract
(ADR-0064 §5.4).

## Above `BLOCK_ROWS`: a typed error that names `push_table`

**Breaking** for alpha.4 callers that wrote one block above `BLOCK_ROWS` rows. Above `BLOCK_ROWS` rows,
`table_job_streaming` fails before it stages anything. The job runs on a worker, so the error surfaces at
`finish()`, not at the call. The error is
`Error::StreamedTable { reason: StreamedTableError::NeedsPartition { rows, max } }`, and its message names
`StreamWriter::push_table`. At or below `BLOCK_ROWS` the job's output is unchanged.

`stream::tests::table_job_streaming_above_block_rows_names_push_table` tests it. The test matches the typed
variant with `rows == BLOCK_ROWS + 1` and checks that the message contains `push_table`. It also checks that the
refusal has no side effect: nothing is left in `staging/` and no `.tsra` exists.

## In-tree callers

Two callers moved to `push_table`. They only needed a staged table encode, and a table of at most `BLOCK_ROWS` rows
written by `push_table` is one staged job:

- `panicking_staged_job_leaves_no_staged_file_once_finish_returns`, the panicking-sibling cleanup test.
- `failed_staged_commit_drops_every_waiting_staged_file`, the waiting-commit cleanup test. Its blocks still reach the
  reorder buffer: the `staged_bytes == 3 · block` spin passes.

The callers that stay are the `#[allow(deprecated)]` sites below. They stay because each one is about the
deprecated job itself.

## `#[allow(deprecated)]` sites, one line each

- `tessera-io/src/lib.rs`, the `pub use stream::table_job_streaming` re-export: the public path stays until the
  job is removed. The item carries its own deprecation.
- `stream.rs` `staged_table_jobs_seal_the_in_memory_product_for_every_worker_count_and_window`: this test pins the
  deprecated job's remaining contract (at most `BLOCK_ROWS` rows, staged output equals in-memory output) until the
  job is removed.
- `stream.rs` `push_table_of_one_block_is_byte_identical_to_table_job_streaming`: the deprecated job is the
  reference that `push_table`'s single block is compared against.
- `stream.rs` `table_job_streaming_above_block_rows_names_push_table`: this test exercises the deprecated job's
  refusal.
- `tests/staged_job_memory.rs`, the import and `staged_table_jobs_hold_no_more_than_the_encoder_itself`: they
  measure this job's heap at most `BLOCK_ROWS` rows. `push_table`'s heap model is #714 (PR F).

Two `#[allow(deprecated)]` sites already on `dev` belong to other deprecations, and this PR leaves them unchanged:

- `container.rs` `block_group_…` test: the legacy flat `block_group` rule, kept under test (ADR-0064 §6).
- `multiblock.rs` `logical_table_concatenates_…` test: `LogicalTableView::prefix`.
