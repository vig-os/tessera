# [PR 691](https://github.com/vig-os/tessera/pull/691) fix(core,io,ingest,cli)!: validate block names into one type and join them by plain components only

Closes #685

Implements the owner decision on #685 (2026-10-29) and records it as **ADR-0063** (Accepted).

## What changes

- **Grammar.** A block name is one or more `/`-separated segments of `[A-Za-z0-9._-]+`, no segment `.`
  or `..`, at most 255 bytes. `tessera_core::block::BlockName` is the one validated type. `BlockRef.name`
  is a `BlockName`, and deserializing a manifest or journal line applies the grammar, so an invalid block
  reference can't be built or read. It serializes as the plain string, so no manifest byte, digest or
  corpus golden moves (the conformance tests pass unchanged).
- **Leaf rule.** No name in one product may be a parent prefix of another. `ProductBuilder::seal`, the
  write session (each append, and `recover`), `unpack` and `pack_dir` refuse a conflict with
  `Error::BlockNameConflict`. Readers don't apply it, so a pyramid sealed as `volume` + `volume/1` still
  opens, verifies and reads in-zip.
- **One filesystem join.** `BlockName::path_under(base)` pushes plain (`Component::Normal`) components
  only, and every block-name path goes through it. `block::name::join_checked` applies the same grammar
  to `aux/` member names.
- **Orphan fragments.** `WriteSession::recover` deletes every file under `blocks/` that no journal line
  names, so a fragment left by an uncommitted append can't block a later append that needs its path as
  a directory (`volume` vs `volume/0`). A fragment some line names is kept even when recovery stops
  before that line, so a journal cut short can still be repaired by hand.
- **`tessera pyramid`** names level 0 `<block>/0` (was `<block>`). A new pyramid unpacks and re-packs
  byte-identically.
- SPEC §5 defines `BlockRef.name` by the grammar. The FEATURE-MATRIX gets a row; the ADR index lists 0063.

## Call sites now going through the type

| Where | Before | Now |
|---|---|---|
| `WriteSession::append_block` (fragment) | `dir.join("blocks").join(&name)` | `fragment_guard` → `BlockName::path_under` |
| `WriteSession::append_staged` / `append_block_from` (`place`) | `blocks.join(name)` | `fragment_guard` → `path_under` |
| `WriteSession::recover` (fragment check) | `dir.join(BLOCKS).join(&r.name)` | grammar check on the raw line, leaf rule, then `path_under` |
| `WriteSession::seal` (fragment list) | `dir.join(BLOCKS).join(&r.name)` | `path_under` |
| `container::unpack`, blocks | `outdir.join("blocks").join(&name)` | leaf rule, then `path_under`, all resolved before any write |
| `container::unpack`, `aux/` members | `outdir.join("aux").join(&name)` | `join_checked`, resolved before any write |
| `container::pack_dir` | `dir.join("blocks").join(&b.name)` | leaf rule, aux names checked, then `path_under`; all before `out` is written |
| `container::write_aux_members` (zip entry `aux/<name>`) | any name | grammar check, before anything is read |
| `container::write_aux_members` rewrite (copied-through `blocks/*`, `aux/*`) | copied as-is | grammar check per entry, before anything is written |
| `container::pack` / `pack_streaming*` (zip entry `blocks/<name>`) | `String` | `BlockName` |

Other joins in the workspace checked and left alone, because they don't take a block or member name:
`repo.rs` (`objects/<alg>/<hex>` from a digest, `refs/` from a sanitised lineage), collection
member files (`member_filename` sanitises the reference), and ingest/CLI paths built from fixed or
generated names.

## Public API changes (breaking, `fix!`)

- `BlockRef.name: String` → `BlockName`. `BlockPayload.name` and `BlockPayload::new(name, …)` take a
  `BlockName`. `pack_streaming` / `pack_streaming_verified` take `&[(BlockName, &Path)]`.
- New: `tessera_core::block::{BlockName, check_leaf_rule}`, the `tessera_core::block::name` module
  (`check_name`, `join_checked`, `NameError`, `MAX_BLOCK_NAME_BYTES`), and the error variants
  `Error::InvalidBlockName { name, reason }` and `Error::BlockNameConflict { parent, child }`.
- `BlockName` derefs to `str`, compares with `str`/`&str`/`String`, and implements `Display` (width-aware),
  `AsRef<str>`, `Borrow<str>`, `FromStr` and `TryFrom<&str | String>`.
- Behaviour: the block builders (`array_block`, `table_block`, `blob_block`, `blob_ref_streaming*`,
  `chunk_index_block`), `commit --add-block`, `write_aux_members` (and its copy-through), seal, the write session, `recover` (which also deletes orphan fragments),
  `unpack` and `pack_dir` now refuse what the grammar or the leaf rule refuses. `tessera pyramid`
  writes `<block>/0`. A manifest with an invalid name fails to parse (`Error::Serde`, message
  `invalid block name '<name>': <reason>`).

## Tests

- `tessera-io/tests/block_names.rs` (13 tests; an old pyramid is also re-packaged with an aux member). Each bad shape (empty, `.`, `..`, `../`, `a/../..`,
  `a/./b`, a leading `/`, `/`, a trailing `/`, `//`, `\`, `..\`, NUL, `C:`, `C:\`, a space, non-ASCII,
  `*`, 256 bytes) is refused at the builders and at deserialization (so neither append path can be
  handed one), at `recover`, `unpack` and `pack_dir`, and by the aux writer. For each, the whole tree
  under the test's root is asserted unchanged, journal bytes included. Also: leaf-rule conflicts at
  both append paths, at `recover`, at seal, `unpack` and `pack_dir`; an old-style pyramid still opens,
  verifies and reads; hierarchical names stream, recover and seal byte-identically to a batch pack;
  every corpus and fixture name validates; `pack_dir` refuses a bad aux name with no archive left
  behind; the archive rewrite refuses to copy an escaping `blocks/`/`aux/` entry through.
- `write::tests`: a failed hierarchical append (either path) removes the directories it created;
  `recover` removes orphan fragments and a hierarchical append follows; a recovery cut short keeps the
  fragments of later lines.
- `block::name::tests`: the grammar's reasons, plain-component mapping, serde round trip, width-aware
  `Display`, the leaf rule (including `volume.cidx` sorting between `volume` and `volume/1`).
- `nav::tests::build_pyramid_writes_downsampled_levels`: `volume/0` + `volume/1`, verify, and
  `unpack` → `pack_dir` byte-identical.
- **Pre-fix proof** (the same assertions run against `origin/dev` 2e9f530, scratch only): 3 of 3 fail.
  `append_block wrote OUTSIDE the session dir`, `recover followed '../../escape'`,
  `unpack accepted '../escape'`.
- `cargo test -p tessera-core -p tessera-io`, `cargo test -p tessera-cli --bins --tests` and
  `cargo test -p tessera-ingest` pass. `cargo clippy --workspace --all-targets --all-features -D warnings`
  is clean.
- Snapshot regenerated: `tessera-cli/tests/cmd/arrays.trycmd` (the `pyramid --help` text). No other
  snapshot moved, and no corpus file changed.
