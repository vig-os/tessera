# [PR 592](https://github.com/vig-os/tessera/pull/592) docs(adr): ADR-0061 DICOM de-identification profile (Accepted)

ADR-0061 for #579, **Accepted** by the owner on 2026-10-18 after four audits. Replaces the 12-tag `PHI_TAGS` with **DICOM PS3.15 Annex E 2026d (Basic Profile)** from vendored tables generated from NEMA's XML.
- Rules R1-R11 go beyond the table, each generated from PS3.6, found by a recorded PS3.3 search or named by an audit: every UI value is replaced; every DA/DT/TM value follows the date rule; every PN is removed; text-VR names, identifier copies (incl. SelectorUCValue), comments and free text are removed; UR attributes are removed; no UN element is sealed.
- Option precedence: the date mode alone governs date-valued attributes. Keyed `2.25.<UUIDv8>` UIDs and a Δ keyed on (issuer, PatientID), both byte-exact with vectors.
- The seal holds the de-identified header and a `dicom_deidentify` record. The originals and paths go into the ADR-0047 envelope. Every member's provenance edges are opaque in a de-identifying run.
- The tests use a per-VR decoding oracle with a no-UN check. §12 is the plan as 14 ready-to-file sub-issues (P1-P5), which never attest ahead of what they enforce; every acceptance criterion cites only parts its own or earlier phases build.
- FEATURE-MATRIX gains a planned row citing ADR-0061.

**Decisions (owner, 2026-10-18), all as recommended:** D1 default flip in P3d · D2 de-identified header from P3b · D3 `also_remove` now ·
D4 GHSA for v0.1.0-alpha.1 · D5 refuse plus a pixel-review ack · D6 custodian key with crypto-shred (allow, warn) ·
D7 redacted spec-hash pre-image for every member.
