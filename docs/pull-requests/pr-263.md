# [PR 263](https://github.com/vig-os/tessera/pull/263) feat(cli): tsra slice --world — mm addressing via the stored affine (#253 phase 2)

`tsra slice <FILE> <BLOCK> --world "L,P,S"` resolves an anatomical world point (LPS mm) to the nearest voxel via the inverse voxel→world affine (`index = R⁻¹·(world−t)`), reporting that voxel (raw or `--physical`). Requires a 3-D array with a `world_frame` (ADR-0030); clear errors on index-space / singular affine. `--index`⊕`--world`. `inv3`/`world_to_index`/`parse_world` unit-tested. Phase 2 of #253. Gate green.
