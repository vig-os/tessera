## [Comment #1](https://github.com/vig-os/tessera/pull/427#issuecomment-5799144644) by [@gerchowl](https://github.com/gerchowl)

_Posted on September 23, 2026 at 05:01 PM_

Superseded by #429 (merged). Root cause: `.github/workflows/release.yml` is *generated* by cargo-dist, whose `plan` job regenerates it and diffs against the checked-in copy — cargo-dist 0.32.0 hard-codes `checkout@v6`, so a hand/dependabot edit of that file can never pass `plan`. #429 adds the `[dist.github-action-commits]` override (`actions/checkout = v7.0.1`) and applies the v7.0.1 bump everywhere; `plan` is green there. Closing this one.
