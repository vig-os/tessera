# [PR 319](https://github.com/vig-os/tessera/pull/319) feat(ingest): actionable non-image DICOM handling — route raw objects to blob (#301)

Addresses the raw-non-image half of #301.

## Problem
`dicom-series`/`dicom` are image-only: a DICOM object with **no pixel grid** (raw sinogram/projection like GE `GEMS_PET_RAW`, structured reports, exam reports) failed deep in the decoder with a cryptic `No such data element with tag (0028,0010)` (surfaced in the DUPLET run).

## Fix
`read_object` now detects a non-image object up front (no `Rows`/`PixelData`) and returns an **actionable** error pointing at the cold/archival tier:
> `non-image DICOM object (no Rows/PixelData — e.g. a raw sinogram/projection, structured report, or exam report). Preserve it bit-faithfully with `tessera ingest blob` …`

Test: a modality-only object yields the blob-tier guidance. (Also adds `_typos.toml` so the hook stops corrupting `VR::PN` literals.)

## Deferred (follow-up on #301)
The **multi-block scout** primitive (a 2-projection localizer → one `.tsra` with 2 image blocks) is a nicety, not a blocker — single-file `tessera ingest dicom` already ingests each projection today. Tracked for a later PR.

Refs: #301
