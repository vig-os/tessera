# [PR 346](https://github.com/vig-os/tessera/pull/346) feat(core): ADR-0052 generation provenance (generic bag) + schema-driven identity inheritance (#324, #342)

## ADR-0052 — generation provenance (generic bag) + schema-driven identity inheritance

Implements [ADR-0052](docs/adr/0052-generation-provenance-and-identity-inheritance.md) (Accepted).
Closes the gaps two fresh-context FAIR reviews found during the DUPLET first-user run.

### What lands
1. **Core spine** (`tessera-core`): structured `Producer{tool,version,git_commit,…}` + untagged
   `ProducerRef` (legacy bare-string producers round-trip **byte-identical**); generic
   `Generation{config: Map, config_ref}` bag (keys never inspected); `inherit_identity(child,parent,schema)`;
   schema `FieldSpec.inherit` + `ProductSchema.requires_generation` (enforced at `validate()`).
2. **Schema declarations**: recon + listmode mark their identity fields `inherit` (schema-driven, no
   engine hardcode). Built-ins ship `requires_generation = false` (permissive).
3. **Ingest wiring** (`tessera-ingest`): the engine walks `derived_from`, inherits schema-flagged
   identity at seal, and attaches `[generation]`/`[producer]` from the spec — on **both** the batch
   and bounded-memory streaming paths, with three-tier precedence `spec > product-own > inherited`.
4. **#343** GEDDF dictionary annotation on **all** listmode tables (singles/coin/time-markers/
   coin-counters), not just quantized events; **#331** nested-path leaf resolution (`/proc_data/events_3p`).

### Boundary (no engine opinion)
Engine = mechanism + struct shapes. Schema = which fields inherit / are PHI / need a recipe. Spec = the
per-run producer + config values. The engine holds no domain field name.

### Reviews addressed
- *Impl-match:* streaming priority inversion → three-tier merge; study inheritance; stronger legacy-seal
  test; ADR `requires_generation` text reconciled with the permissive-builtins decision.
- *Seal/back-compat:* the `inherit` flags + structured producer shift **fresh** seals — read path is
  unbroken (existing `.tsra` still verify), goldens regenerated (corpus + trycmd). Conformance 3/3.

### Acceptance proof — real DUPLET DP01 (~180 GB, 8 products)
Re-ingested `.dat → singles → coin_{2p,3p} → events_{2p,3p}` + time-markers/coin-counters:
- `dat-raw`: `producer=ge-duplet-daq`, `generation.config` = the DAQ `.ini` recipe (10 keys).
- **3-hop inheritance**: `events-2p` (← coin-2p ← singles ← dat-raw) carries `patient_id`/`exam`/
  `study_date`/`acquisition_*` inherited from the raw; `coincidence_mode` stays per-level (not inherited).
- integrity verifies; all columns dictionary-annotated.

`cargo test --workspace` green; clippy `-D warnings` clean.
