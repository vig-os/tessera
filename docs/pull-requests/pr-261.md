# [PR 261](https://github.com/vig-os/tessera/pull/261) feat(cli): ls/tree surface the embedded schema, extra/ namespace, and sidecar files

`ls`/`tree` showed only meta/blocks/sources — the self-describing **schema** (#248) and the **extra/** namespace (full DICOM header, #255) were invisible, and adjacent **sidecars** weren't listed. Now `ls FILE` lists `schema/` + `extra/`; `ls FILE schema` prints the field roster; `ls FILE extra/dicom_header` dumps the header; `tree` gains schema/extra/sidecars sub-trees (signature .sig.json + fcrypt.json when present). Seal stays in the manifest, not a sidecar. Unit-tested; navigating.trycmd regenerated. Groundwork for the one-file/self-contained direction (#259).
