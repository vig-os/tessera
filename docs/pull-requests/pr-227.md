# [PR 227](https://github.com/vig-os/tessera/pull/227) chore: remove legacy fd5 scaffold + template CI — clears all 40 Dependabot alerts

## What

Removes the pre-Tessera **`fd5` "vigOS Python template" scaffold** and the CI/devcontainer layer that existed only to serve it. **Supersedes #226** (which merely patched the scaffold's `uv.lock`) — this clears **40/40** alerts at the root instead of 38/40.

## Why it's safe

The root `fd5` project is dead weight:
- `src/fd5/` is an empty stub, `main.py` is a hello-world, `tests/test_example.py` is `assert True` + a version check.
- **Nothing imports `fd5`.**
- Its `dev` extra's `jupyter`/`ipykernel` are the **sole source of all 40 Dependabot alerts** (the notebook stack).
- main's whole `ci.yml` was the template's CI — `lint` (pre-commit, *not even installed* → red on every PR), `test` (pytest on stubs), `security` (bandit on the empty `src/`). None tested anything real. Tessera's gate is `nix flake check` on the dev branch.

## Removed
- Root scaffold: `src/fd5`, `main.py`, `tests/`, `pyproject.toml`, `uv.lock`
- `.devcontainer/` (fd5-themed template) + root `justfile`/`justfile.project` (only orchestrated the devcontainer recipes) — dev is the **nix devShell (direnv)** now
- `ci.yml`: dropped `lint`/`test`/`security`; kept `dependency-review`; `summary` → `needs: [dependency-review]`. **Also removes the broken pre-commit job that red-X'd every PR.**
- `release.yml`: dropped the `uv run pytest` job; `release` → `needs: [validate, finalize]`

## Rewired
- `setup-env`: `python-version-file` (deleted pyproject) → pinned `python-version: "3.12"`
- `dependabot.yml`: pip `/` → `/tessera/bench/ecosystems` (the one real first-party Python env)

**40 files, ~5k lines** of dead template removed. No first-party Tessera code touched.

## Bonus
Removing the broken `pre-commit` lint job means PRs to `main` can finally go green (it was failing on *every* PR, including all 9 open Dependabot PRs).
