# [PR 247](https://github.com/vig-os/tessera/pull/247) polish(cli): elide + group multi-file provenance in tree/ls/inspect

`tree`/`inspect`/`ls sources` dumped hundreds of KB on a DICOM-series `.tsra`, because a series' `ingested_from` is a comma-joined list of every slice path (890 for a CT lung series). Reported from real-data use on `ct-lung.tsra`.

## Fix
- **tree / inspect**: collapse a multi-file edge to `<first path> (+N more)`; middle-elide a long single path keeping the filename tail (`compact_reference`).
- **ls sources**: a real **grouped** listing — `role <- N files in <common-dir>/` then one relative filename per line (common prefix stripped), capped at 8 with a `… (+N more)` footer (`source_lines` + `common_dir`).
- **`--full`** on inspect/tree/ls prints references verbatim / lists every file.

## Proof (real 890-slice CT lung series)
`tree` → `ingested_from <- /home/.../…6623611.IMA (+889 more)` (one line).
`ls sources` → `890 files in /home/.../VEN_CT_2_0_BL57_AXIAL_LUNG_0006/` + 8 relative filenames + `… (+882 more, --full to list all)`.

Pure helpers (`compact_reference` / `source_lines` / `common_dir` / `elide`) unit-tested: the 890-slice case collapses in tree, groups in ls, and expands under `--full`; single-file edges stay one-liners. Full `nix flake check` green; no trycmd snapshot churn (help sections wildcarded, sample fixture has single-file sources).
