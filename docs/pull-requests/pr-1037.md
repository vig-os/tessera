# [PR 1037](https://github.com/vig-os/tessera/pull/1037) fix(io): a crashed init can be retried; init never writes into a refused directory

Closes #1007

Concurrent external changes: if entries appear after init's read-only preflight but before it opens the writer lock,
validation under the lock refuses initialization and can leave the lock file. Removing it could split coordination
with another process already holding or waiting on that lock's inode, so it remains in place.
