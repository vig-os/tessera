# [PR 749](https://github.com/vig-os/tessera/pull/749) feat(io): hold push_table's workers before they read, and test the W + 1 bound

Refs #713 (part 2 of 3)

ADR-0064 PR E, part 2: the read-hold test seam and the ADR-0064 §8 barrier test for `StreamWriter::push_table`
(part 1 is #747). Part 3, the `table_job_streaming` deprecation, opens after this one merges.

## What changes

- `StreamWriter::hold_table_reads() -> ReadHold` (`#[doc(hidden)]` test seam): while the `ReadHold` lives,
  `push_table`'s leaf jobs wait before they read their staged input, so the `W` blocks handed to workers stay on
  disk. `ReadHold::stats` reads the writer's `StreamStats` while `push_table` blocks on the calling thread. A dead
  pipeline releases the waiters. #714's heap model holds its workers with it.
- `held_workers_pin_w_plus_one_staged_input_blocks`, for `W` ∈ {1, 2, 3} at `block_rows = 2 · ROWS_PER_GROUP`, with
  `2W + 1` full blocks plus a partial one offered:
  - **the free-worker gate:** with every worker held, the hand-over of block `W` waits. The reader stalls
    (`producer_stalls` rises) with `jobs_pushed == W`, having pulled exactly `2 (W + 1)` row-groups. A reader that
    pulls past block `W` fails the test while it runs instead of hanging it;
  - `peak_staged_input_blocks == W + 1` exactly, mid-fill, at the stall and at `finish`;
  - **a partial block's bytes:** at the second row-group of block `W` (that block partly filled),
    `peak_staged_input_bytes` equals the summed record sizes of every row-group written so far, the partial block's
    included; at the stall it equals all `2 (W + 1)`;
  - released, the product's canonical manifest equals `TableMultiBlockSink`'s partition of the same rows, and
    `staging/` is empty.

## Evidence

- `cargo test -p tessera-io --lib -- --test-threads=4`: 212 passed, exit 0.
- Mutation run (not committed): `dispatch` submits with the free-worker gate off (`submit(.., false)`). The test
  fails in 0.19 s at `W = 1` with `pulled 5 groups past the W + 1-th block` (exit 101).
- Before this change the test doesn't exist and can't compile (no `hold_table_reads`).
