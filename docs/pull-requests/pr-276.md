# [PR 276](https://github.com/vig-os/tessera/pull/276) docs(adr): ADR-0044 sparse · 0045 units · 0046 time — decide the data-model spikes (#218/#219/#220)

Three design ADRs (Proposed) deciding the open data-model spikes. **0044 (sparse, #218):** scatter-sparse = a Vortex `(coord…, value)` table (reuses Merkle/stats/pushdown/SQL) + `fill_value`/count=0-prune for block-sparse; no bespoke sparse codec. **0045 (units, #219):** UCUM on `unit` + `_vocabulary`/`_code`; quantity = `raw + (slope,intercept,unit)`, store-don't-compute; derived quantities are products. **0046 (time, #220):** three roles kept distinct — `timestamp` RFC-3339 UTC (sealed), `aux/provenance.json:ingested_at` (outside seal), event/elapsed time = integer-tick quantity via `Referenced::time_*` (closes the listmode `ms`-semantics gap). Each ratifies what's built + names the gaps. Gate green.
