# [PR 266](https://github.com/vig-os/tessera/pull/266) feat(format): self-contained .tsra — embed signature + ingest provenance as non-sealed aux/ members (#259)

Makes a `.tsra` a **one-file, never-lose-stuff** artifact: the detached signature and an ingest-provenance record now ride **inside** the zip as non-sealed `aux/` members — the "`.gitignore`-for-the-seal" model (ADR-0042).

- **Seal-ignore invariant (proven):** adding/removing an `aux/` member leaves `content_hash` + `manifest_hash` + the on-disk `manifest.json` **byte-identical** → the conformance corpus is untouched. Enforced at write time + locked by `aux_members_are_carried_but_ignored_by_the_seal`.
- **Embedded signing (default):** `tsra sign` writes `aux/signatures/<key_id>.sig.json` inside the file; `--sidecar` keeps the detached form; `verify-sig` prefers embedded, falls back to sidecar. Same ed25519-over-`manifest_hash` envelope (ADR-0037) — only its *location* moves. Round-trip + wrong-key-reject tested.
- **`ingested_at` provenance:** `aux/provenance.json` (`ingested_at` wall-clock + producer + host) — outside the seal, so a wall-clock timestamp does NOT break writer-determinism (insulated via `TESSERA_SKIP_PROVENANCE` / `ProvenanceOptions` for byte-identical tests).
- `tree` shows an `aux` node; `ls FILE aux/provenance.json` dumps it; `unpack`/`pack` round-trip the aux subtree.
- ADR-0042 (Proposed) + README row.

Full `nix flake check` green (incl. DataFusion `sql-tests`). Deferred: co-signing (multi-key roster), `inspect` `ingested_at:` line, ADR-0041 `aux/fcrypt.json`. Closes #259.
