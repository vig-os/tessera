# [PR 316](https://github.com/vig-os/tessera/pull/316) feat(ingest): tessera ingest ge-hdf5 --quantize — opt-in float→int16 transform (#310)

Implements #310 (and the ge-hdf5 population half of #307) as an **opt-in ingest transform** — default off → byte-identical output, protecting the corpus/`manifest_hash` invariant.

**Stacked on #307 (PR #312)** — needs `Column.scale`. Review/merge #312 first.

## What
`tessera ingest ge-hdf5 <in> <out> --quantize` (also a `quantize` field on the `hdf-compound` spec format):
1. **Annotates** every column with unit/description/short_name from the embedded GEDDF dictionary (#307 population).
2. **Requantizes** the reconstructed float columns (`en`/`vtx`/`lt`) to **int16** at the physical resolution (physical = `raw × scale`): en ×10 (0.1 keV), vtx ×80 (0.0125 mm), lt ×1000 (1 ps). ~2× smaller, physically lossless (600–1000× under measurement resolution — the #310 benchmark).

Non-finite columns (mostly-NaN `lt_corr`) stay float. Integer columns (`ms`/`ax`/`tx`/counts) are annotated but untouched. `--quantize` forces the batch path (the streaming slab writer has no transform seam yet).

## Design
- `apply_geddf_dictionary(group, data, quantize)` — pure, unit-tested transform (annotate + requantize).
- Dictionary embedded via `include_str!` (flake src filter += `/docs/dictionaries/`); `quantize_scale` added to the float entries.
- `to_listmode_product_partitioned` gains an `Option<Vec<Column>>` schema override (None = byte-identical default); `to_listmode_product_with_schema` is the annotated public entry.

## Tests (7 new)
dict-parse, base-field, group-map, annotate+quantize, annotate-only, NaN-skip, and an **end-to-end seal test** proving the annotated int16 schema reaches the manifest. Full `clippy --all-targets --all-features -D warnings` + all gates green.
