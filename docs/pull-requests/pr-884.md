# [PR 884](https://github.com/vig-os/tessera/pull/884) feat(io)!: record the codec profile in every sealed table spec

Closes #869

## What

Owner decision 2026-11-15 on #869: "Record it". A sealed table spec now records a codec-profile id beside
`TableSpec.edition`, so "same input + same edition + same profile → same bytes" can be checked from the product alone.

- **ADR-0024**, dated 2026-11-16 amendment: `TableSpec.codec_profile`, id `tessera-table-v<N>`, starting at
  `tessera-table-v1`. That id names today's codec set (compact preset with Pco; ALP, ALPRD, integer Pco, Delta and
  OnPair excluded; `core2026.08.3`) and the pinned vortex 0.93.0 compressor. The amendment says when the id is bumped
  and what it promises: byte determinism with the edition, not decodability. Readers never refuse a block whose
  profile is unknown or absent.
- **tessera-core**: `TableSpec.codec_profile: Option<String>`, `skip_serializing_if` None, so pre-profile specs keep
  their exact bytes.
- **tessera-io**: `table::TABLE_CODEC_PROFILE` sits beside `TABLE_EDITION`. `table::sealed_spec` already records the
  edition and now records the profile too, so it is the one path that stamps every table block, partition leaf and
  sequenced leaf. A spec naming another profile gets `Error::Codec`, and on streamed paths that happens before anything
  is staged.
- **tessera-cli**: `inspect` prints `edition <id>  codec_profile <id>` under each table block, and `-` when a key is
  absent.
- **Drift guard**: `table::tests::codec_set_matches_the_pinned_codec_profile` pins two things in a hand-written
  literal: `TABLE_EDITION`, and the built compressor as its `Debug` prints it (schemes in try order with their refined
  modes, plus root exclusions). Change the codec set without bumping the profile and the test fails, telling you to
  bump the profile, amend ADR-0024 and regenerate the goldens. A heuristic change inside a scheme doesn't show in that
  print, so the corpus goldens cover it; the ADR says so.
- SPEC §5b and the CHANGELOG (Unreleased, breaking for `TableSpec` struct literals).
