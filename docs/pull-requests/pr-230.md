# [PR 230](https://github.com/vig-os/tessera/pull/230) feat: opaque blob/"junk" block — bit-faithful preservation of un-parsed vendor raw (#229)

Closes #229.

## What

`BlockKind::Blob` — seal an **un-parsed** vendor file (Siemens `.l64` listmode, GE `.7z`/`.cal`, PDF, log) **verbatim**, digest = `blake3(bytes)`. It rides the existing hash-on-write → Merkle `content_hash` → `manifest_hash` seal → signature machinery unchanged, so `tessera verify` proves bit-faithfulness for free and `tessera extract` recovers the bytes **byte-identical**.

The container's pack/verify path is already kind-agnostic, so this needed **no new storage path** — only a producer pairing `blake3(bytes)` with the raw payload + a self-describing `BlobSpec {filename, media_type?, size}`.

## Surface
- **core**: `BlockKind::Blob` + `block::blob::BlobSpec` + built-in `blob` product schema
- **io**: `blob::blob_block` / `spec_of`; round-trip-byte-identical unit test
- **ingest**: `blob::to_blob_product` + `FormatOptions::Blob` (`format="blob"`, serde alias **`junk`**)
- **cli**: `tessera extract <tsra> <block> <out>`; `tessera ingest blob` (hidden **`junk`** alias); blob tree/inspect display; CLI e2e test (`ingest junk → verify → extract == bytes`)
- **corpus**: deterministic `blob_opaque` fixture + regenerated `corpus.json` goldens
- **docs**: SPEC §5e · ADR-0038 · ADR README + FEATURE-MATRIX rows

## Easter egg
`junk` is an accepted alias at the human entry points (`tessera ingest junk …` and `format = "junk"`) — same machinery, for vendor files that have earned the name. The **stored** kind is always `blob` (determinism + a clean corpus).

## FAIR framing
A blob is **F**/**A**/**R** + integrity-verified but **not Interoperable** until decoded — a *preservation companion* to the normalised array/table products, never a replacement (a raw blob and a derived product coexist in one sealed `.tsra` via a `derived_from` edge).

## Verification
Green `nix flake check` (workspace test/clippy/fmt, wasm, OCI/WORM/registry roundtrips, guardrails incl. adr-matrix, conformance corpus). Smoke-tested on a real opaque file: `ingest junk → tree → verify → extract` = byte-identical.
