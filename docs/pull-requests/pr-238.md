# [PR 238](https://github.com/vig-os/tessera/pull/238) docs(adr): ADR-0040 — data protection (sensitivity tiers · consent erasure · field confidentiality)

Proposed ADR capturing the data-protection model: schema-driven **sensitivity tiers** on `FieldSpec` (PS3.15-seeded, versioned), **consent-withdrawal erasure** (destructive `redact` via forget/gc + crypto-shred for shared copies), and **field-level confidentiality** (`age` envelope-encrypt sensitive fields to recipient pubkeys → coded/anon-by-default-if-leaked; sidecar keeps the seal deterministic; revisits ADR-0007 for the share/leak threat model). Docs-only. Implementation phased — PHI hygiene + the sensitivity-tier spike are separate issues.
