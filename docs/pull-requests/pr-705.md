# [PR 705](https://github.com/vig-os/tessera/pull/705) fix(deps): bump libz-sys to 1.1.31 (RUSTSEC-2026-0418)

Closes #704

RUSTSEC-2026-0418 flags `libz-sys <= 1.1.30` because its build script prints the whole build environment once `cc >= 1.6.0` is in use. `tessera/Cargo.lock` pinned 1.1.29, so the cargo-deny advisories gate failed and blocked every push.

- **Change:** only the lockfile, via `cargo update -p libz-sys --precise 1.1.31`. libz-sys is the only package that moves (2 lines), and `deny.toml` has no ignore.
- **Exposure:** we resolve `cc 1.2.65`, which is below the 1.6.0 that triggers the leak. No earlier build leaked anything, so there's no cache purge or secret rotation.

## Evidence (seat)
- `cargo deny check advisories`: exit 1 before the bump (`error[vulnerability] … RUSTSEC-2026-0418`), exit 0 after (`advisories ok`).
- `nix build -L .#checks.x86_64-linux.feature-snapshots`: exit 0, so no snapshot regeneration was needed.
- The pre-commit and pre-push gates pass, including the cargo-deny hook that failed before.
