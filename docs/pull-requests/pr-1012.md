# [PR 1012](https://github.com/vig-os/tessera/pull/1012) feat(core): object-kind discriminator and collection member diff (ADR-0067 step 3)

Zero-block product manifests can also parse as collections, so repository readers need an explicit discriminator.
Add `ObjectKind::of` using the ADR-0067 top-level key rule, with typed ambiguous-kind errors and strict JSON parsing.

Add the pure `collection::diff` API: added and removed members, repinned references (seal or kind changes), and
relative order changes among shared members. Results follow collection order and duplicate references are refused.
Public rustdoc describes scope, ordering, errors, and reconstruction requirements. Add root and core Unreleased notes.
