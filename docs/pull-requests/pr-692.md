# [PR 692](https://github.com/vig-os/tessera/pull/692) docs(spike): design a deadlock-free bound on the Vortex writer's pending segments

Refs #681

Design note for a deadlock-free bound on the Vortex writer's pending segments
(`docs/spikes/681-vortex-writer-backpressure.md`). Docs only; no code change.

- Root cause at `gerchowl/vortex@608d8a1`, with file:line: sink starvation on the single-threaded
  executor (grows with the input) plus a size-independent order debt `D` from the `SequenceId` order.
- Reproduction: `buffered(2)`, `buffered(8)` and the literal #681 candidate at `B = 1` deadlock
  deterministically (exit 3, deadlock detector, id dumps).
- Decision: an input gate on pending sink bytes with a starvation override. It is deadlock-free for
  every `B`, byte-identical, and bounded by `B + D + ε + K`.
- ksb `vortex-681-sweep-1` (`--cpu 4 --exclusive-cpus --mem 8Gi --time 60`): exit 0, 64 runs
  (61 completed, 3 deadlocked as predicted).
  - Consumer shape at 268 M rows: peak heap 834 MB → 134 MB.
  - Random `u64`: 2,007 MB → 16 MB.
  - One SHA-256 per input across budgets and executor threads.
  - No throughput cost.
- Plan for the implementation round: the Vortex patch, tests, the upstream PR, the tessera pin bump,
  the `WriteConfig` knob, the ADR-0026 amendment and the ksb RSS proof. Open questions each carry a
  recommendation.
