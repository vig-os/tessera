# [PR 839](https://github.com/vig-os/tessera/pull/839) docs(adr): record the ksb RSS proof of push_table (ADR-0064 PR G, part 2)

ADR-0064 PR G, part 2 of 2: the record of the ksb RSS proof of `StreamWriter::push_table` (§8.1, as amended by #760,
#770 and #797). Part 1, the jobs and the evaluator, is #767 (merged `22b10bf`); the criterion-2 amendment is #829
(merged `146c040`).

## What

- **ADR-0026: the results record** ("Measured (ADR-0064 §8.1 RSS proof, #715 G r4, 2026-11-11)"): the jobs and
  their exit codes, every criterion's numbers, the across-run slope and shared-disk timings as context, and the
  detection floors the run met. The table is reproduced below.
- **ADR-0064 A.2:** erratum for the 256-leaf spread (163.09–186.53 MB, +14.4 %), and a pointer to the r2 diagnosis
  note.
- **`docs/spikes/715-rss-proof-diagnosis.md`:** the r2 diagnosis ADR-0064 cites.
- **FEATURE-MATRIX:** `push_table` (#713) moves to Landed (#757 item 1), and the logical-tables row lists the proof
  as landed, with its jobs and the `rss-proof-evaluator` check.
- **`run.py` / `test_run.py`:** fixes a review nit on #767. No test pinned that each tenth is its *maximum*, so a
  first-, last- or minimum-sample mutant of `tenth_peaks` passed all 52 self-tests.
  - `test_tenth_peaks_take_each_tenths_maximum` builds a log by hand with several samples per tenth, the peak neither
    first nor last, and asserts the literal values `[70, 120, 0, 9, 0, 0, 0, 0, 0, 55]`. That covers an empty tenth
    as 0, and the seal's samples falling in the last tenth.
  - `log_tenths`' docstring is corrected: r1's 64-leaf `W = 1` CSV is 481 KB, so not every r1 CSV is over 1 MiB.
