# [PR 322](https://github.com/vig-os/tessera/pull/322) Tessera supersedes fd5 — graduate spike/tessera-core to dev (then main)

## What

Graduate **Tessera** (`spike/tessera-core`) to be the canonical tree, superseding **fd5** (FAIR Data on HDF5, the HDF5 predecessor). Staging on `dev` first to shake out CI, then `main`.

- **Tessera = "fd5 v2"** — substrate-agnostic (manifest + shape-dispatched array/table/blob blocks, Nix-managed), the successor to fd5's single-HDF5-file model. The whole current build lives here: format core, ingest (DICOM/GE-HDF5/NIfTI/raw/blob), write engine, collections + schemas, signing, WORM, OCI, Python/WASM bindings, conformance corpus + SPEC.
- **fd5 is archived** at tag `fd5-archive` (dev's final state) — its history is also preserved as an ancestor of this commit.

## Mechanic (why it's conflict-free despite divergent structures)

`dev`/`main` (root-level `crates/fd5`, HDF5) and `spike` (`tessera/`-nested, Nix) forked from `0901bb1` into incompatible layouts. This commit is `merge -s ours` of `main`+`dev` into spike: it **takes Tessera's tree wholesale** while recording fd5's `main`+`dev` history as ancestors — so it's a clean *descendant* of both (no conflicts), and CI runs on it.

## Heads-up — first CI exposure

Every feature was gated by local `nix flake check` (x86_64), but **the GitHub matrix has never run on this body of work**. Expect this PR to *shake out*:
- **`aarch64-linux` (ARM)** — the x86==ARM determinism goldens are wired but never proven green; most likely to surface.
- **CodeQL / cargo-deny / dependabot** — never gated on spike.

This is the intended shakedown. On green here → merge to `dev`, then the same commit graduates to `main`. Then future work branches off `main` and fd5 retires.
